===== PAGE 4 =====
01 课前准备 为什么是网站，不是 PDF
PDF 传统作品集
只能放静态图，动效、视频全放不进去
文件体积受限，塞多了发都发不动
改一版要重新导出、重新发一遍
对方只能"看"，不能"逛"
Web 作品集网站
视频、动效、滚动交互都能放
一条链接发出去，手机电脑都能打开
改内容就是改文件，随时更新
本身就是一件作品：它证明你会用 AI 做东西
对找工作、投比赛的同学：网址本身就是简历里最能打的一行。这门课的终点，就是一条能发出去的链接。
===== PAGE 5 =====
01 课前准备 先选类型：你要哪一种个人网站
个人网站的核心价值是"匹配需求与场景"。主流就三类，先选清楚，后面的素材和页面都跟着它走。
A
内容分享型
博客、技术笔记、行业观察。核心是"内容可读、
检索方便"，文字是主角。
适合：想沉淀教程和思考的人
B
作品展示型
作品是绝对主角，不只"放作品"，更要"讲清作
品价值"。设计师、插画师、独立开发者的核心
载体。
本课选它：对接课程作品和比赛
C
个人品牌综合型
相当于"个人官网"：作品、博客、简介、联系方
式全整合。适合自由职业和求职进阶。
适合：个人品牌定位明确的人
选型的判断标准只有一条：访客是谁、他想在你这里看到什么。想不清楚这一点，页面做得再花也没有用。
===== PAGE 6 =====
01 课前准备 素材先行：先有内容，再谈界面
Codex 只负责"摆"，不负责"编"。打开对话框之前，先把这三样东西备齐。
A
你的作品
课程作业、比赛作品、设计图、视频，都归到一
个文件夹里。每个作品配一句说明：它是什么、
你做了哪部分。
放到最后一步才想起来找，一定来不及。
B
你的文字信息
姓名与一句自我定位、经历时间线、技能标签、
联系方式。全部写成纯文本，提示词里直接粘。
这类信息最容易被 AI 编造，必须自己给全。
C
你的参照截图
从下一页的网站里，挑 2–3 张你喜欢的首屏截
图存下来。"我想要这种感觉"配图说，比一百个
形容词都准。
截图直接拖进 Codex 对话框就能用。
检查标准：随便挑一个作品，你能在 30 秒内说出它是什么、你做了什么、它好在哪。说不出来就先补这一条。

提示词框架
整个教程只有一条"公式"，但它决定了成品的下限：
说清楚五件事，再开口。
身份介绍 + 风格定义 + 框架描述 + 注意点 + 信息补充
同一个框架，从首屏用到最后一屏，从建站用到迭代。
===== PAGE 33 =====
02 提示词框架 五段式对话框架
01 身份介绍你是谁、要做什么、给谁看。一句话就够。
02 风格定义要什么气质：简约 / 高级 / 科技感。最好直接附上一张对标截图。
03 框架描述这一屏分几块、每块放什么。这是五段里最需要想清楚的一段。
04 注意点提前说"别踩什么"：适配 PC 和手机、文字别压在人物上。 05 信息补充真实的姓名、链接、联系方式。不给，它就编。
缺任何一段，Codex 都会自己"脑补"——脑补出来的东西，往往不是你想要的。
===== PAGE 34 =====
02 提示词框架 首屏提示词实例：
身份介绍 我是一名大四学生，要做一个个人作品集网站，给招聘方和比赛评委看。
风格定义 整体浅色系，干净、克制，参考这张截图的气质（附对标截图），不要像模板网站。
框架描述 首屏一屏：导航栏（左侧名字 Logo，右侧三个锚点）、大标题、一句副标题、两个按钮（看作品 / 联系我），下方作品卡片横向滑动。
注意点 要同时适配电脑和手机；文字不压在图片主体上；不要任何占位假数据。
信息补充 我的名字是 XXX，邮箱 xxx@xxx.com，作品图片在 D:\portfolio\img 文件夹里，先完成首屏，给我一个本地可预览的网页。
写完就发，第一次别追求完美——它给什么你就改什么，下一页讲怎么改。

两条路线
到达同一个终点的两条路：
一条快，一条稳。赶时间走第一条，练手感走第二条。
路线一 · 先风格，后内容 约 1–2 小时
从参考站复制一个成品提示词，让 Codex 先复刻出完整框架，再把内容
换成你的。
路线二 · 从 0 到 1 搭五屏 约 1–2 周
用五段式框架一屏一屏搭，每屏单独迭代。费时间，但每一处都是你的
决定。
===== PAGE 40 =====
03 两条路线 路线一 · 复刻四步
1
在参考站看中一个效果，复制它的 Prompt
Motionsites 每个案例都带"复制提示词"，Design Prompts 按风格流派整理。
2
粘给 Codex，加一句话
"根据这个文件生成对应的本地网站，我要做后续调整"——先要框架，不要内容。
3
拿到一个完成度很高的空壳
整站动效、结构、配色都在，只是里面的字还是参考站的。别动结构，只换内容。
4
用"信息补充"把内容换成你的
下一页讲这一步怎么写。换完直接进部署（第四章）。

03 两条路线 信息补充：把空壳变成"你的"
一条信息补充提示词，把要改的东西一次说全：
首屏标题改为"XXX 的作品集"，小标题"数字媒体 · 2026 届"；首屏放三个按钮：课程作品、比赛作品、联系我，分别跳到对应位置；
作品卡片换成 D:\portfolio\img 里的 12 张图，每个配一行说明；鼠标悬停到联系按钮上，显示我的邮箱。
四类必须由你提供的信息
① 所有真实文字
标题、介绍、经历。AI 不知道你是谁，你不给它就编。
② 素材文件的路径
图片视频放好文件夹，把路径告诉它，它会自己取用和命名。
③ 每个按钮去哪里
跳转到哪一屏、哪个链接。不说清楚，导航就是摆设。
④ 交互的小动作
悬停显示什么、点击弹什么窗。这些效果一句"参考这张图"就能复用。
===== PAGE 53 =====
03 两条路线 路线二 · 五屏结构，一屏一屏搭
作品集网站的通用骨架。每屏都是一次独立的五段式对话，做完一屏验收一屏。
第一屏 首屏 Hero 大标题 + 副标题 + 三个入口按钮，第一眼决定去留
第二屏 个人介绍 照片 + 自我定位 + 数据亮点 + 经历时间线
第三屏 作品页面 按类别分块展示，点击出大图弹窗——核心屏，占一半精力
第四屏 个人优势 3–5 个能力卡片，每张配数据或案例支撑
第五屏 联系方式 一句行动号召 + 联系卡片 + 二维码，收尾即转化
顺序不必照抄，但"作品屏最花精力、联系屏最不能省"这两条别变。

03 两条路线 作品页的核心单元：一张作品卡片
第三屏的每一张作品卡，都要交代五件事。缺一件，访客就要多想一步。
01 封面 一张能代表作品气质的图，尺寸统一，别东倒西歪
02 名称与类型 叫什么、属于哪一类（视频 / 设计 / 交互），让访客快速归类
03 一句话亮点 它好在哪。写结果和特色，不写"用心制作"这类空话
04 可打开的成品 点进去能看完整版——视频能播、页面能开，别只给截图
05 你负责的部分 团队合作的作品要写清分工——面试官最关心的就是这一条
给 Codex 的写法：把五件事写进信息补充段，"每张作品卡片包含封面、名称与类型、一句话亮点、成品链接、我的分工"。

04 上线与注意 技术栈怎么选：AI 时代的新答案
你不用会写，但要说得清"要什么"。选之前先过三个问题：
① 核心功能是什么 静态展示，还是要复杂交互？
② 以后常改吗 需要持续更新内容模块，还是上线就基本不动？
③ 想顺便学技能吗 只想出成品，还是想借机了解前端？
三个常见选择，一句话定位：
Astro / Hugo
静态站点，加载快、上手易。展示型作品集的最优解。
React / Vue
组件化框架，交互上限高、教程最多。想深入前端选
它。
无代码平台
Framer、Webflow 等。完全不碰代码，下一页细说。
本课的做法：技术栈直接写进提示词交给 Codex 拿主意，但"要什么效果"必须你自己说清。

04 上线与注意 无代码平台 vs 自部署
无代码平台
Framer · Figma Site · Webflow
+ 可视化拖拽，有自带内容管理，编辑方便
+ Figma 设计稿能直接转成网站
− 站点被平台锁定，用得越久越迁不走
− 免费版受限：作品数量少、带水印，去水印、自定义域名都要付费（每月几
十到上百）
自部署
Vercel · Netlify · Cloudflare · GitHub Pages
+ 免费额度足够个人用，域名一年几十块
+ 自由度拉满：3D 预览、复杂动效、交互原型都能上
− 有学习成本：要懂一点文件结构，跟着文档和 AI 走会慢一点但走得通
一句话结论：临时展示页用无代码，长期个人品牌选自部署。"免费 + 精美 + 零学习"不存在——付费换时间，免费花心思。

04 上线与注意 部署三条路
Codex Sites 最推荐
对 Codex 说"帮我把网站部署到 Sites"，剩下的
它来。免费，几分钟出一条公网链接。
适合：作业提交、比赛演示、发给老师看。第一次
上线选这个。
Netlify
把整个网站文件夹拖进网页就发布，免费。国内访
问速度不稳定，作为备用方案。
适合：Codex 额度用完的时候。拖拽即发，不需要
懂任何服务器知识。
阿里云
买域名和服务器（几十块起），部署自己的站点。
国内访问稳定，网址可以是你自己的名字。
适合：想长期维护、挂在简历上的正式作品集。要
做实名备案，多花一两天。
交作业的最短路径：Codex Sites 免费 → 拿到链接 → 写进简历和报名表。

04 上线与注意 文件迁移：换电脑接着做
机房和宿舍两台电脑轮流做？用 Git 仓库当中转站。两段话直接发给 Codex：
A 电脑
带走
"把本地这个文件夹建立成 Git 仓库并提交，远程仓库地址是 XXX。仓库里要包含网站的全部资源、记录和记忆。"
提交一次，你的整个项目就上了云，本地坏了也不怕。
B 电脑
接上
"我的 Git 在线仓库地址是 XXX，把里面的内容克隆到本地 XXX 文件夹。"
克隆完继续对话，Codex 会接着上次的进度做。
更进一步：每次大改版都提交一个版本，改砸了能回退——这是工程里最值钱的习惯。

04 上线与注意 上线只是开始：一个链接放到所有能放的地方
网站做完不算完，链接要用起来。六个去处，今天就能放：
① 简历里的个人主页
简历顶部一行，替代"作品见附件"。
② 求职邮件的签名
每封邮件自动带上，看的人比自己想象的多。
③ 社交平台的主页
站酷、小红书、B 站简介区的第一行。
④ 作品集文档与接单介绍页
PDF 末尾放链接，文档管细节，网站管全貌。
⑤ 微信名片与社群自我介绍
一句话加链接："我的作品都整理在这里：xxx"。
⑥ 面试时的自我介绍
开口第一句就给链接，面试官当场能翻。
链接的作用是把「下载—解压—播放」变成一步。凡是需要对方动手的入口，都在漏人。
