## 照片团改成「圆球」分布（用户：不要宽宽扁扁的，要像在一个圆球里）

- 真 3D 方案（全新）：① .cluster 加 perspective:800px（0×0 盒子的透视原点=屏幕中心=球心）；② hero.js 把落点 parseFloat 成极坐标——dataset.ang=atan2(y,x)、dataset.rn=半径/R_OUT(16.5)，动画循环里 th=ang+rot，rotateY=cos(th)·TILTMAX·rn、rotateX=-sin(th)·TILTMAX·rn（TILTMAX=34°），照片"朝球外"倾斜且随整团旋转保持物理一致；③ 景深 translateZ=(d-1)·130px 透视下自动近大远小；④ CSS --dof（rn>0.3 起算）做景深虚化 blur(≤1.3px)+saturate 降；⑤ 悬停 --lift:60px translateZ 真抬升（透视下变大），filter:none 解虚化。
- transform 链：translate(-50%,-50%) → translate3d(x,y,z) → rotate(--rot) → rotateY → rotateX → translateZ(var(--lift))；place() 抽成函数，reduce-motion 下初始化时摆一次（amp 不为 0 也不漂）。

## 首屏改成「地球仪式作品球」（用户给的完整交互规格）
- 旧模型废弃：SPOTS 二维落点 + 整团 2D rotate。新模型：12 张卡片按经纬度贴球面（CARDS 数组 lon/lat/w），逐帧算球面三维坐标，整球只绕垂直轴转动（纬度不变→永不上下翻转），±58° 钳制（不 360° 整圈）。
- 惯性：wheel 只往 vel 累加（每 1px→0.03deg，单帧上限 6deg），每帧 vel*=0.78 推进 rotT，rot 以 0.12 追 rotT → 平滑带惯性；到边界（±58°）继续同向滚 → 放行页面滚动（可进作品区），回顶自动重新可用。
- 转头角钳制（YAW_MAX 50° / PITCH_MAX 38°）：真实经度会让贴到球侧的照片被透视压成一条线，钳制后侧卡保持可读。
- 遮挡与景深：zIndex 由 z 决定；背面卡 opacity 0.4~1 + blur ≤1.8px（量化 0.2px 一档，只在变化时写 filter，防掉帧）。
- 沉浸模式：html.hero-immersive（scrollY<60）隐藏 .nav 与 .hero__scroll，.hero__status 上移 top:26px；nav 加了 opacity/transform 过渡。
- 坑：①动画循环若用 document.hidden 门控启动，headless 截图环境下不跑 → 改为无条件 start()，visibilitychange 只负责暂停；②agent-browser 会话在链中途也可能被重置（之前 y3/y5 截图全白就是这原因），长链要分段重开验证。
- 验证：rotateY 18°→-9.26°→-54°（滚 400px≈27°）；第 4 次滚轮 sy=400 且 nav opacity=1；移动端球 330px 宽（scale 1.15）；悬停 caption「[09] 开源 Markdown 编辑器」正常。截图 .preview/g1-init.png、g2-rot1.png、g3-rot2.png、h1-works.png、h2-mobile.png。

## 「照片铺满的地球仪」+ 自由转 360°（用户：要转360度，照片应该充满球的表面）
- 布局从 12 张二维散点/黄金角螺旋改为**纬度环带**（7 圈共 58 张桌面 / 46 张窄屏，12 封面循环）。关键教训：黄金角螺旋整球均匀但半球不均匀，某些转角正面缺纬度段 → 球散架；环带纬度固定，任何转角正面都盖满。
- **旋转模型重写**：转角正比滚动量（rotT += d·0.4）+ 惯性（KICK/DECAY），无角度上限；单向累计转满 360° 放行页面滚动（turned 在 loop 里按每帧实际 step 统计），回顶重置。⚠️ 角速度钳制模型（MAX_VEL）会导致转一圈要十几格滚轮，已废弃。
- **大 bug：yaw 未归一化**。yaw=clamp(lon0+rot,±55)，rot 超过 ~100° 后所有卡片 yaw 全被钳在 ±55 → 球整体歪头散架（截图诊断+导出坐标定位）。修复：lonW 先 %360 归一化到 ±180 再钳制。修复后 0/137/274/411/548° 全部是饱满的球。
- 观感补强：①背面卡 opacity 地板 0.22+blur≤2.2px，从前排缝隙透出背面照片（球读作实心）；②球侧卡片向心收缩 scale=1-rim·0.22 防止切线卡戳出轮廓；③卡片加白边相框（bg#fff+padding+1px 边），浅封面也能读出是照片；④占位图最浅 6 张再加深一档。
- 截图排查方法论：用 window.__ball 调试钩子把球钉在固定角度逐个截图，比模拟滚轮盲测高效得多（钩子保留在 hero.js 末尾）。
- 验证：0~548° 五个角度截图全是球；真实滚轮 7 格 → 转满一圈后 sy=600/900、nav 淡入；移动端球 342×365；悬停 caption「[07] 食堂点餐小程序」正常。截图 .preview/r4-*.png、e1-mid.png、e2-works.png、e3-mobile.png。
